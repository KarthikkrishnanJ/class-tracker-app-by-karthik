# Contributing to Class Tracker App

Thanks for your interest in contributing! This document explains how to get involved.

## Getting Started

1. **Fork the repository** - Click the "Fork" button at the top right
2. **Clone your fork** - `git clone https://github.com/YOUR-USERNAME/class-tracker-app-by-karthik.git`
3. **Create a branch** - `git checkout -b feature/your-feature-name`
4. **Make your changes** - Edit files and test locally
5. **Commit your changes** - `git commit -m "Add your message here"`
6. **Push to your fork** - `git push origin feature/your-feature-name`
7. **Open a Pull Request** - Submit your PR with a clear description

## Types of Contributions

### 🐛 Bug Reports
Found a bug? Open an issue and describe:
- What you were doing
- What happened
- What should have happened
- Screenshots if helpful

### ✨ Feature Ideas
Have an idea to improve the app? Create an issue and explain:
- The problem it solves
- How it would work
- Why it would help students

### 📝 Documentation
Help improve README, guides, or code comments

### 💻 Code
Fix bugs or add features. Start with issues labeled "good first issue"

## Development Setup

```bash
# Clone the repository
git clone https://github.com/KarthikkrishnanJ/class-tracker-app-by-karthik.git
cd class-tracker-app-by-karthik

# Install dependencies
npm install

# Run the development server
npm run dev
```

## Code Guidelines

- Write clear, readable code
- Test your changes before submitting
- Keep commits focused and well-described
- Comment complex logic

## Questions?

Open an issue or discussion if you need help!
