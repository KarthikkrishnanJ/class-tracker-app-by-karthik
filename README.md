# Class Tracker Web

A modern student productivity and class management website.

## Current Version

### V1

* Attendance tracking
* Study timer
* Push Notification Sytem + Sound
* Timetable system
* Notes and productivity tools
* Responsive interface

## Upcoming

### V2 (In Development)

Planned improvements:

* Better UI/UX
* Faster performance
* More customization
* Improved analytics
* Enhanced study tools
