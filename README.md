# Class Tracker Web

A modern student productivity and class management website.

## Website
https://class-tracker-app-by-karthik.vercel.app

## Getting Started
1). Open the above link

2). Select Sign Up
    <img width="1862" height="939" alt="image" src="https://github.com/user-attachments/assets/f9d74734-4802-4380-b4a5-3a7176703dcc" />

3). Fill in your details
    <img width="1845" height="935" alt="image" src="https://github.com/user-attachments/assets/8339621e-fef9-4f77-8d1e-f0bb06d014a6" />

4). Select Sign Up(no verification required)
    <img width="1847" height="934" alt="image" src="https://github.com/user-attachments/assets/2097d657-2362-4870-8d92-450dd249f3fa" />

5). Select your timezone and select add your subjects
<img width="1843" height="931" alt="image" src="https://github.com/user-attachments/assets/b6eea384-bda6-480e-9245-12a594928344" />

6). Add and remove subjects
<img width="1849" height="944" alt="image" src="https://github.com/user-attachments/assets/15a06769-effa-49ff-be12-66f236f0254c" />

7). Add your schedule and timings here
    <img width="1854" height="946" alt="image" src="https://github.com/user-attachments/assets/57df00b1-7ddf-4b13-8ded-e8b447a4415a" />

Feel free to explore the website as you wish.

Note : For users switching accounts please go to Manage tab, inside data tab, select export data(json format) from your previous account and import into new account from the same place
